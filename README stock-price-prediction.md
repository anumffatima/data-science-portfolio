# Stock Price Prediction using Machine Learning

## Overview
This project predicts future stock prices using historical stock data (Open, High, Low, Close, Volume).

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- yfinance

## Model Used
Linear Regression

## Results
- Model trained on historical Apple stock data
- Evaluated using MSE and R2 Score

## How to Run
Open the Jupyter Notebook in Google Colab or Jupyter and run all cells.

## Dataset Source
Yahoo Finance via yfinance API
